# Pm Stakeholder Mgmt — MAARS Reference

## Overview
Stakeholder management — RACI matrix, influence mapping, communication plans, alignment

## Core Framework
Use structured approach: define goal, identify audience, create hypothesis, execute, measure.

## Key Prompts
- "For [company], create a pm stakeholder mgmt strategy targeting [audience]. Goal: [metric]. Current state: [X]. Provide specific recommendations with examples."
- "Analyze [company] pm stakeholder mgmt and suggest 3 improvements prioritized by impact."
- "Write a pm stakeholder mgmt template for a [type] SaaS company with [pricing/audience]."

## Best Practices
1. Start with customer research and data before tactics
2. Test hypotheses with small budgets before scaling
3. Measure leading indicators, not just lagging metrics
4. Document what works for each specific audience/channel
5. Iterate based on data, not opinions
