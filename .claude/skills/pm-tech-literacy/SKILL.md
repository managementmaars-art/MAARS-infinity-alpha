## Overview
Technical literacy for PMs — APIs, databases, system design basics, working with engineers

## Core Framework

## Key Prompts
- "For [company], create a pm tech literacy strategy targeting [audience]. Goal: [metric]. Current state: [X]. Provide specific recommendations with examples."

## Best Practices
1. Start with customer research and data before tactics
2. Test hypotheses with small budgets before scaling
3. Measure leading indicators, not just lagging metrics
4. Document what works for each specific audience/channel
5. Iterate based on data, not opinions
