# Pm Feature Spec — MAARS Reference

## Overview
Feature specification — functional requirements, edge cases, mockup briefs, dev handoffs

## Core Framework
Use structured approach: define goal, identify audience, create hypothesis, execute, measure.

## Key Prompts
- "For [company], create a pm feature spec strategy targeting [audience]. Goal: [metric]. Current state: [X]. Provide specific recommendations with examples."
- "Analyze [company] pm feature spec and suggest 3 improvements prioritized by impact."
- "Write a pm feature spec template for a [type] SaaS company with [pricing/audience]."

## Best Practices
1. Start with customer research and data before tactics
2. Test hypotheses with small budgets before scaling
3. Measure leading indicators, not just lagging metrics
4. Document what works for each specific audience/channel
5. Iterate based on data, not opinions
