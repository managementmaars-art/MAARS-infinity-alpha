# Test Impact Analysis - MAARS Reference

## Overview
Test impact analysis - coverage mapping, change detection, selective test execution

## Core Framework
Use structured approach: define goal, identify audience, create hypothesis, execute, measure.

## Key Prompts
- "For [project], implement test impact analysis for [use case]. Requirements: [X]. Provide working code examples."
- "Analyze [existing implementation] and suggest 3 improvements prioritized by impact."
- "Write a test impact analysis template for a [type] project with [specific requirements]."

## Best Practices
1. Read official documentation before implementation
2. Test in isolation before full integration
3. Handle errors and edge cases explicitly
4. Document configuration and requirements
5. Monitor and alert on key metrics

- Setup and initialization
- Core operations
- Error handling and retries
- Authentication and security
- Performance and scaling
