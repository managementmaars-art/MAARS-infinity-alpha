# Quick Start Guide - Software Tool Research Skill

## Test the Skill

Try these example prompts to see the skill in action:

### 1. Quick Repository Assessment (5 minutes)

```
Analyze the arxiv-mcp tool in this workspace and give me a quick quality assessment.
```

**Expected output:**
- Quality scores (1-5 stars) for documentation, testing, maintenance
- Key findings (strengths and weaknesses)
- Recommendation (adopt/evaluate/avoid)

---

### 2. Architecture Analysis (10 minutes)

```
Create a detailed architecture analysis of arxiv-mcp with component diagrams 
showing how the different modules interact.
```

**Expected output:**
- High-level architecture overview
- Component diagram (Mermaid)
- Module structure explanation
- Dependency graph
- Data flow description

---

### 3. Quality Metrics Deep Dive (15 minutes)

```
Measure all quality metrics for arxiv-mcp including code quality, 
documentation, testing, and security.
```

**Expected output:**
- Comprehensive metrics across 5 dimensions
- Specific findings with file references
- Composite quality score
- Recommendations for improvement

---

### 4. Security Assessment (5-10 minutes)

```
Check arxiv-mcp for security issues and vulnerabilities.
```

**Expected output:**
- Categorized security issues (critical/high/medium/low)
- Specific code locations
- Fix recommendations with examples
- Security score

---

### 5. Full Comprehensive Report (20-30 minutes)

```
Generate a complete software tool analysis report for arxiv-mcp including 
architecture, functionality, quality metrics, and recommendations.
```

**Expected output:**
- Executive summary
- Complete architecture documentation
- Functional analysis
- Quality assessment across all dimensions
- Risk assessment
- Detailed recommendations

---

## Expected Skill Behavior

### When You Mention the Skill

The skill activates automatically when you ask questions like:
- "Analyze this repository..."
- "What's the architecture of..."
- "Compare tool X and tool Y..."
- "Is this codebase well-maintained?"
- "Check for security issues in..."

### What the Skill Will Do

1. **Read the skill instructions** from SKILL.md
2. **Follow the systematic workflows**
3. **Use reference materials** when needed
4. **Generate structured output** with diagrams and metrics
