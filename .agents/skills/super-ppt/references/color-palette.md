# 晋升答辩 PPT 配色系统

基于企业晋升述职报告的完整配色方案。

## 快速参考

### 主色
| 颜色 | HEX | 用途 |
|------|-----|------|
| 🟠 品牌橙 | `fc5a1f` | 标题、关键词、CTA |
| 🔵 企业蓝 | `3669cd` | 数据图表、次要强调 |

### 文字色
| 颜色 | HEX | 用途 |
|------|-----|------|
| ⬛ 深灰 | `434343` | 主标题 |
| ⬜ 中灰 | `707070` | 正文 |
| 🔘 浅灰 | `a4a4a3` | 辅助信息 |

### 背景色
| 颜色 | HEX | 用途 |
|------|-----|------|
| ⬜ 纯白 | `ffffff` | 主背景 (60-70%) |
| 🔲 浅灰 | `f8f8f8` | 卡片背景 |
| 🔷 蓝白 | `e6edf9` | 分区背景 |

### 强调色
| 颜色 | HEX | 用途 |
|------|-----|------|
| 🟠 浅橙 | `fca787` | 渐变、装饰 |
| 🟢 浅绿 | `d7e8df` | 成功状态 |
| 🔵 浅蓝 | `93aee3` | 图表填充 |

## Python 使用

```python
from ppt_editor import THEMES

promotion = THEMES["promotion"]
colors = promotion["colors"]

# 获取颜色
primary = colors["primary"]      # fc5a1f
secondary = colors["secondary"]  # 3669cd
```

## 配色原则

1. **主次关系**
   - 品牌橙 `#fc5a1f`: 5-10%
   - 企业蓝 `#3669cd`: 3-5%
   - 灰色系: 20-30%
   - 白色系: 60-70%

2. **对比度要求**
   - 标题与背景: ≥ 4.5:1
   - 正文与背景: ≥ 4.5:1
