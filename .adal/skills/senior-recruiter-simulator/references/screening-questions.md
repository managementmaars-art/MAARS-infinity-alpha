# Screening Questions (HR Screener)

## Apertura (2-3 min)

```
"Hola [Nombre], gracias por tu tiempo hoy. Soy [Sarah] del equipo
de Talent. Esta es una llamada inicial de 20-30 minutos para
conocernos mejor. Te parece bien si empezamos?"

"Antes de empezar, cuentame: como te enteraste de nosotros?"
```

## Pitch Personal (5 min)

### La Pregunta

```
"Cuentame un poco sobre ti y tu trayectoria profesional."
```

### Que Evalua

```
- Claridad de comunicacion
- Estructura del mensaje
- Relevancia al rol
- Confianza sin arrogancia
```

### Follow-ups

```
- "Que te motivo a hacer ese cambio de [X] a [Y]?"
- "De todo lo que mencionas, que es lo que mas disfrutas?"
- "Como describirian tus companeros tu estilo de trabajo?"
```

### Red Flags

```
[ ] Pitch de 5+ minutos sin estructura
[ ] No menciona logros concretos
[ ] Habla mal de empleadores anteriores
[ ] No conecta experiencia con el rol
```

---

## Motivacion (5 min)

### Preguntas

```
"Por que te interesa esta posicion?"

"Que sabes sobre [Empresa]?"

"Por que estas buscando un cambio ahora?"

"Que te atrajo de nuestra job description?"
```

### Que Evalua

```
- Investigacion previa sobre la empresa
- Alineacion genuina con el rol
- Motivacion real (no solo dinero)
- Red flags de salida anterior
```

### Follow-ups

```
- "Que esperas aprender en este rol?"
- "Como ves este rol ayudandote en tu carrera?"
- "Que te haria quedarte 3+ anos en una empresa?"
```

### Red Flags

```
[ ] "No se mucho de ustedes, pero vi el puesto..."
[ ] Solo menciona salario/beneficios
[ ] Critica abiertamente al empleador actual
[ ] Respuestas genericas sin especificidad
```

---

## Experiencia Relevante (10 min)

### Preguntas

```
"Cuentame sobre tu proyecto mas reciente."

"Cual ha sido tu mayor logro tecnico?"

"Describe un dia tipico en tu rol actual."

"Que tecnologias usas dia a dia?"
```

### Preguntas Especificas para Senior Full-Stack

```
"Has trabajado con arquitecturas multi-tenant?"

"Cuentame sobre tu experiencia con integraciones de terceros."

"Has trabajado con equipos distribuidos/remotos?"

"Que experiencia tienes con bases de datos a escala?"
```

### Follow-ups

```
- "Cual fue tu contribucion especifica en ese proyecto?"
- "Cuantas personas habia en el equipo?"
- "Cuanto tiempo tomó? Que hubieras hecho diferente?"
- "Como mediste el exito de eso?"
```

### Red Flags

```
[ ] No puede explicar su contribucion especifica
[ ] Usa "nosotros" pero no puede decir que hizo el
[ ] Vaguedad en tecnologias ("trabaje con bases de datos")
[ ] No menciona resultados o impacto
```

---

## Expectativas y Logistica (5 min)

### Preguntas

```
"Cual es tu expectativa salarial para este rol?"

"Cual es tu disponibilidad para empezar?"

"Tienes alguna restriccion de horario o ubicacion?"

"Estas en otros procesos actualmente?"
```

### Para Roles Remotos

```
"Has trabajado 100% remoto antes?"

"Como es tu setup de trabajo en casa?"

"Que timezone manejas normalmente?"

"Estarias disponible para travel ocasional?"
```

### Que Evalua

```
- Expectativas realistas vs mercado
- Disponibilidad real
- Compromiso con el proceso
- Transparencia
```

### Red Flags

```
[ ] Expectativa muy por encima del rango sin justificacion
[ ] "Necesito respuesta esta semana" (presion)
[ ] Evasivo sobre otros procesos
[ ] Inflexibilidad total
```

---

## Cierre (3 min)

### Preguntas del Candidato

```
"Que preguntas tienes para mi sobre el rol o la empresa?"
```

### Evaluar Calidad de Preguntas

```
BUENAS:
- "Como es el equipo con el que trabajaria?"
- "Cuales son los mayores challenges del equipo ahora?"
- "Como es el proceso de onboarding?"
- "Que define exito en los primeros 90 dias?"

MALAS:
- "Cuantos dias de vacaciones hay?"
- "Puedo trabajar desde otro pais?"
- "Cuando hay aumento de sueldo?"
- (No tener preguntas)
```

### Proximos Pasos

```
"Gracias por tu tiempo. Nuestro proceso es:
1. Esta llamada (hoy)
2. Entrevista tecnica con el equipo
3. Entrevista con Hiring Manager
4. Oferta

Te contactaremos en [X dias] con feedback.
Tienes alguna pregunta sobre el proceso?"
```
