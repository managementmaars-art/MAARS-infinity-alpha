# Behavioral Questions (Hiring Manager)

## Apertura (2 min)

```
"Hola [Nombre], soy [Jennifer], Engineering Manager del equipo.
Hoy quiero conocerte mejor como profesional y entender como
trabajas. Voy a hacerte preguntas situacionales - no hay
respuestas correctas, solo quiero entender tu experiencia real."
```

---

## Ownership y Autonomia

### Preguntas

```
"Cuentame sobre un proyecto donde tuviste ownership end-to-end."

"Dame un ejemplo de cuando tomaste una decision importante
sin tener toda la informacion."

"Describe una situacion donde identificaste un problema
que nadie mas habia visto."

"Cuentame sobre algo que mejoraste sin que te lo pidieran."
```

### Follow-ups (STAR)

```
- "Cual era el contexto exacto?"
- "Que opciones consideraste?"
- "Por que elegiste ese approach?"
- "Cual fue el resultado medible?"
- "Que aprendiste de eso?"
```

### Que Evalua

```
- Iniciativa proactiva vs reactiva
- Capacidad de tomar decisiones con ambiguedad
- Ownership real vs "participe en"
- Impacto demostrable
```

### Red Flags

```
[ ] Solo ejemplos donde "el equipo" hizo cosas
[ ] No puede cuantificar impacto
[ ] Espera instrucciones detalladas
[ ] No menciona decisiones propias
```

---

## Colaboracion y Conflicto

### Preguntas

```
"Cuentame sobre un desacuerdo tecnico con un companero.
Como lo resolvieron?"

"Dame un ejemplo de cuando tuviste que influenciar a alguien
sin autoridad directa sobre esa persona."

"Describe una situacion donde recibiste feedback negativo.
Como reaccionaste?"

"Cuentame sobre un proyecto donde el equipo no funcionaba bien.
Que hiciste?"
```

### Follow-ups

```
- "Cual era la perspectiva de la otra persona?"
- "Que intentaste primero que no funciono?"
- "Como llego a la resolucion?"
- "Cambiaria algo de como lo manejaste?"
```

### Que Evalua

```
- Manejo de conflicto constructivo
- Capacidad de influencia
- Ego saludable (puede estar equivocado)
- Colaboracion efectiva
```

### Red Flags

```
[ ] Siempre tiene la razon en sus historias
[ ] Culpa a otros por conflictos
[ ] No puede ver perspectiva del otro
[ ] Evita conflicto en lugar de resolverlo
```

---

## Fracaso y Aprendizaje

### Preguntas

```
"Cuentame sobre un proyecto que fallo o no salio como esperabas."

"Dame un ejemplo de un error significativo que cometiste.
Que aprendiste?"

"Describe una decision tecnica que tomaste y resulto ser incorrecta."

"Cuentame sobre una vez que subestimaste algo. Que paso?"
```

### Follow-ups

```
- "Que senales ignoraste?"
- "Cuando te diste cuenta del problema?"
- "Como lo comunicaste al equipo/manager?"
- "Que harias diferente hoy?"
```

### Que Evalua

```
- Honestidad y vulnerabilidad
- Capacidad de auto-reflexion
- Ownership de errores
- Aprendizaje genuino
```

### Red Flags

```
[ ] "Nunca he tenido un proyecto que falle"
[ ] Culpa factores externos exclusivamente
[ ] No puede articular aprendizaje
[ ] Minimiza el fracaso
```

---

## Presion y Prioridades

### Preguntas

```
"Cuentame sobre una vez que tuviste que entregar con
un deadline imposible. Como lo manejaste?"

"Dame un ejemplo de cuando tuviste que decir 'no' a
un stakeholder importante."

"Describe una situacion donde tuviste demasiadas
prioridades competiendo. Como decidiste que hacer?"

"Cuentame sobre un momento de alta presion.
Como mantuviste la calma?"
```

### Follow-ups

```
- "Que sacrificaste para cumplir?"
- "Como comunicaste el riesgo?"
- "Que apoyo pediste?"
- "Lo harias igual hoy?"
```

### Que Evalua

```
- Manejo de stress
- Priorizacion efectiva
- Comunicacion bajo presion
- Balance scope/quality/time
```

### Red Flags

```
[ ] "Siempre cumplo todo" (no realista)
[ ] No puede priorizar, todo es urgente
[ ] Trabaja 80 horas como solucion default
[ ] No pide ayuda nunca
```

---

## Liderazgo y Mentoria

### Preguntas

```
"Cuentame sobre alguien a quien hayas mentorado.
Como fue la experiencia?"

"Dame un ejemplo de cuando tuviste que dar feedback dificil."

"Describe una situacion donde lideraste sin ser el 'jefe'."

"Como ayudas a un junior que esta trabado en un problema?"
```

### Follow-ups

```
- "Como adaptaste tu estilo a esa persona?"
- "Que resultado tuvo tu mentoria?"
- "Que aprendiste tu de esa experiencia?"
```

### Que Evalua

```
- Capacidad de multiplicar impacto
- Paciencia y empatia
- Liderazgo sin autoridad
- Inversion en otros
```

---

## Motivacion y Carrera

### Preguntas

```
"Que te motiva en tu trabajo dia a dia?"

"Donde te ves en 3-5 anos?"

"Que tipo de problemas te emociona resolver?"

"Que buscas en tu proximo rol que no tienes hoy?"

"Que te haria quedarte en una empresa por 5+ anos?"
```

### Que Evalua

```
- Alineacion con el rol
- Expectativas realistas
- Motivacion intrinseca vs extrinseca
- Fit a largo plazo
```

### Red Flags

```
[ ] Solo motivado por dinero/titulo
[ ] Quiere ser manager en 6 meses
[ ] No tiene clarity sobre que quiere
[ ] Expectativas no alineadas con el rol
```

---

## Preguntas del Candidato

### Preguntas Que Impresionan

```
- "Cuales son los mayores challenges del equipo ahora?"
- "Como es el proceso de toma de decisiones tecnicas?"
- "Que define exito en los primeros 90 dias?"
- "Como manejan deuda tecnica vs features nuevas?"
- "Como es la cultura de feedback en el equipo?"
```

### Red Flags

```
[ ] Solo preguntas sobre beneficios
[ ] No tiene preguntas preparadas
[ ] Preguntas que muestran no investigó la empresa
```
