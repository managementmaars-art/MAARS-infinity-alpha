# 拾象「海外独角兽」风格写作

将研究素材转化为拾象品牌调性的投研文章。

这个 skill 专注于**写作输出**。它假设素材已经准备好（来自 company-research 的 Research Pack，或用户提供的原始材料）。如果素材不足，先用 company-research 补齐，再开始写作。

## 关于拾象的写作声音

拾象的声音是一位身处硅谷和中国之间、对 AI 技术有深度理解的投研分析师在对一群同样聪明的读者说话。语气是克制的自信——从不喊口号，但每篇都有明确的机构立场。节奏是"判断在前、数据在后"的倒金字塔式推进。核心美学是将最前沿的技术概念用投资语言重新编码，让读者读完后不仅知道"发生了什么"，更知道"这意味着什么、钱应该往哪走"。

## Step 1: 确认文章类型

| 类型 | 适用场景 | 篇幅 |
|------|---------|------|
| 公司深度研究 | 单公司深度分析 | 4000-8000 字 |
| 投资地图 | 赛道全景 + 多公司拆解 | 3000-5000 字 |
| Best Ideas | 预测/观点列表 | 每条 300-600 字 |
| AGIX PM Notes | 周期性市场洞察 | 主论文 1500-3000 字 |
| 人物专访 | 深度对话整理 | 3000-5000 字 |

## Step 2: 素材检查

**公司深度研究**必须有：行业痛点数据、至少 1 个创始人访谈引用、killer feature 描述、收入/增长硬数字、2-3 家竞品对比。缺什么补什么。

## Step 3: 语言 DNA（从 50 篇范文提炼）

### 核心规则

**1. 中英混用是表达工具，不是装饰**
英文术语承载"圈内共识概念"，翻译反而损失精确度。每句话 1-3 个英文术语。
✅ "定价逻辑正在从 Seat 转向 Outcome，从卖工具走向 Selling Labor"
❌ "Agent（智能体）正在改变企业的工作流（workflow）"

**2. 判断打头，数据跟进**
先亮明观点，再用数据证明。
✅ "Token 消耗量才是衡量 AI-native 程度的核心指标。OpenClaw 单次消耗是 ChatGPT 的 10 倍以上。"
❌ "根据数据显示，token 消耗量在过去一年增长了 300%，因此我们认为……"

**3. 数字说话，形容词让路**
每段至少 1 个具体数字。
✅ "ARR 在两年内增长 27 倍" ❌ "ARR 增长迅猛"

**4. 跨时代类比**
将 AI 现象映射回互联网历史或其他行业——这是拾象最有辨识度的修辞。
✅ "Google 凭借'模型+TPU+云+产品'构建端到端生态，类似 LLM 时代的 Apple"

**5. "不是 X，而是 Y"**
制造认知反差，修正错误直觉。
✅ "Rogo 的切入点不是再造一个数据库，而是在分析师已有的工作环境里直接嵌入 AI 能力。"

**6. 开头 = 宏大数据 + 具体矛盾**
✅ "全球投行业每年处理超过 3.5 万亿美元的交易，但驱动这台机器运转的，是每周超过百小时的初级分析师。"

**7. 新概念附一句话定义**（不是括号注释英文）
✅ "Temporal 的核心概念是 Durable Execution，即确保所有工作流都能被可靠执行。"

**8. 开头预告核心观点**
✅ "本文试图回答三个问题：1. OpenClaw 的爆发意味着什么？2. ..."

**9. 看好必须写风险**
绝不只唱多。投资亮点后紧接 2-3 条潜在风险。

**10. "我们看好/我们认为"**
始终"我们"，从不"我"。明确的机构立场。

### 格式
- 小标题：`01.` `02.`，4-12 字
- 段落短：2-4 句即换行
- 数字带时间戳
- 结尾止于判断，不升华

### 绝对禁止
❌ "震惊""史诗级""未来已来""颠覆性" ❌ "综上所述""总而言之" ❌ 省略号、感叹号 ❌ "Agent（智能体）" ❌ "本文将介绍" ❌ Emoji ❌ 第一人称"我" ❌ 学术式引言结论

## Article Templates

详见 `references/templates.md`（如需完整模板）。以下是核心骨架：

### 公司深度研究
```
Hook（200-400字）→ 大数字+痛点+引出主角 → 亮点3条+风险2-3条
01. 行业痛点  02. XXX是谁？  03. 产品与技术  04. 商业模式
05. 市场规模  06. 竞争格局  07. 融资时间线  08. 团队
结尾："我们看好……" 或创始人引用
```

### 投资地图
```
Hook → 定义（不是X而是Y）→ 全景分层（3-5层）→ 重点公司拆解（8-15家）→ 赢家特征 → 拾象逻辑
```

### Best Ideas
```
导语 → Idea 01~N（标题=判断性陈述 + 背景+逻辑+举例，300-600字/条）
```

### AGIX PM Notes
```
主论文（提问→反常识→新框架→启示）→ 市场总结 → AI Alphas 5-8条
```

### 人物专访
```
引题 → Q&A（按话题分节，小标题6-12字）→ 止于最后一问一答
```

## Post-Writing Checklist
- [ ] 开头有宏大数字+具体矛盾？
- [ ] 前3段预告核心观点？
- [ ] 每大节≥2个具体数字？
- [ ] 看好同时写了风险？
- [ ] 有"我们看好/认为"？
- [ ] 体现≥1个拾象命题？（斜率优先 / AGI Basket / SaS / Long-Horizon Agent / 中美互补）
- [ ] 无流量词、无总结句、无emoji、无感叹号？
- [ ] 英文自然嵌入？
- [ ] 结尾止于判断？
